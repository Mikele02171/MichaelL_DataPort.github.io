AFL Player Performance Data Engineering Pipeline 2012 - 2025

End-to-End Data Engineering & Medallion Architecture

Context

The goal of this project is to build an end-to-end data engineering pipeline that transforms AFL player performance data from 2012 to 2025 into structured, analytics-ready datasets. The pipeline integrates multiple seasons of player statistics, applying data cleaning, standardisation and feature engineering to support player performance tracking, fantasy football analysis and interactive Power BI dashboards.

What I Did

  • Developed an ETL pipeline using Python and Pandas to ingest, clean and process AFL player performance datasets spanning 2012 to 2025.
  • Implemented a Medallion Architecture consisting of Bronze (raw), Silver (cleaned) and Gold (analytics-ready) data layers to organise and structure the data processing workflow.
  • Integrated more than 10 yearly datasets using pd.concat() to create a unified, multi-season AFL player performance dataset.
  • Standardised data schemas, handled missing values and aligned season formats to improve data consistency and reliability.
  • Performed feature engineering to calculate fantasy points, key performance indicators (KPIs) and player impact metrics for performance analysis.
  • Established consistent player-to-team-to-season mapping to support accurate player tracking and historical performance comparisons.
  • Prepared analytics-ready datasets for downstream analysis, fantasy football insights and Power BI dashboard development.

Tools

Extract, Transform, Load (ETL) with Python and Pandas, Sport Analytics, Excel, Power BI, DAX
